# 横屏提词器 Teleprompter

一个**零依赖、单文件**的网页版提词器,为手机口播 / 视频拍摄设计。
双击 `index.html` 即可在浏览器打开,无需安装、无需后端、无需账号。

## ✨ 功能

- **贴稿即用**:粘贴或编辑稿子,稿子自动本地保存(刷新不丢)。
- **匀速滚动**:开始 / 暂停 / 继续 / 重置,基于 `requestAnimationFrame` + 时间增量,不同刷新率手机上速度一致。
- **镜像翻转**:一键水平镜像,适配提词器反光玻璃场景。
- **黑底白字**:提词页纯黑高对比大字,防反光眩光。
- **横屏 / 竖屏可选**,进入前自选朝向。
- **可调**:字号、滚动速度、文字宽窄(左右边距)、阅读基准线开关。
- **倒计时开始**:可选 关闭 / 3 / 5 / 10 秒,点开始后倒数再滚动。
- **屏幕常亮**:提词时用 Screen Wake Lock 防止息屏(需 https 或主屏启动)。
- **极简界面**:正文几乎占满全屏,操作收进右上角图标 + 弹出式设置面板。

## 🚀 使用

**电脑上**:直接双击 `index.html`。

**手机上(同一 WiFi)**:在电脑项目目录起一个静态服务,手机访问电脑局域网 IP——
```bash
python -m http.server 8080
# 手机浏览器打开 http://<电脑IP>:8080/
```
> 想测「屏幕常亮 / 全屏」需要 https(局域网 http 不算安全环境)。可把文件夹拖到任意免费静态托管(如 Netlify Drop)拿到 https 链接,再「添加到主屏幕」从图标启动即全屏。

## 🛠 技术

单个 `index.html`,内联 CSS + 原生 JavaScript,**无框架、无构建步骤、无 npm 依赖**。
- `ARCHITECTURE.md` — 架构设计与技术方案
- `HANDOFF.md` — 迭代交接 / 开发清单
